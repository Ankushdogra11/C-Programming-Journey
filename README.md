# C Programming Workspace

A small C project for writing and running programs.

## Quick start

1. Open `main.c` and write your code.
2. Run the project to compile and execute it.

You can also use the shell:

```bash
make       # compile the program
make run   # compile and run the program
make clean # remove compiled files
```

The compiler uses C17 and enables common warnings so mistakes are easier to spot.
